# What-A-Budget

Offline Financial Tracker.

A Flutter project designed for secure, on-device personal finance management.

## Features

- **Local SQLite Database:** Persistent, isolated on-device data storage.
- **Custom Budget Thresholds:** Configurable target budgets with variable timeframes (Daily, Weekly, Bi-Weekly, Monthly, Yearly).
- **Dynamic Theme Engine:** Support for Light, Dark, and AMOLED Dark modes via Material 3.
- **State Management:** Riverpod-driven reactive UI updates.
- **Data Portability:** Local backup and restore mechanisms.
